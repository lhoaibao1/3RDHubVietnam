Chữ ký email 3RDHub Vietnam

Điền thông tin, xem trước bên phải, bấm Sao chép chữ ký rồi dán vào phần cài đặt chữ ký của Gmail, Outlook hoặc ứng dụng thư của bạn.

  1. Gmail: Cài đặt → Xem tất cả cài đặt → Chữ ký → Tạo mới → dán (Ctrl/Cmd + V) → Lưu.
  2. Outlook: Tệp → Tuỳ chọn → Thư → Chữ ký → Mới → dán.
  3. Apple Mail: Cài đặt → Chữ ký → dán (bỏ chọn "luôn khớp kiểu thư mặc định").
